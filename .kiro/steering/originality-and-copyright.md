# Originality and Copyright Boundaries

This project is a Kiroween 2026 Skeleton Crew entry and must respect the
competition's original/new-work requirements and third-party intellectual
property. These rules are binding on all generated code, content, and assets.

## New work only

- Write new code and create new assets for this project.
- The prior 2018 Beepy project may be disclosed as inspiration where
  appropriate, but do **not** copy its code or assets and do **not** assume
  ownership of a contributor's old artwork.
- Do not reuse artwork, text, audio, or code whose rights we do not hold.

## Clinical content boundaries

- Beepy's Clinical Cards uses disease-based high-yield facts. It must **not**
  use NBME-style vignette questions and must **not** include copyrighted NBME
  items or any copyrighted question bank content.
- Clinical content ships as authored/reviewed JSON. Any future AI-assisted
  clinical generation requires medical review before use and is out of scope
  for the initial build.

## Visual style

- Use a modern, polished visual style. Do **not** use retro / 8-bit / pixel-art
  styling.

## Licensing and attribution

- The repository carries a detectable open-source license (`LICENSE`, MIT).
- Attribute any third-party libraries per their licenses.
- Before publishing, re-check the live official Kiroween rules for IP and
  originality requirements.
